# Agent Guidelines for Virtual Trade Show Commercial V1

## Rules of Engagement
1. **Safety First**: Only modify files within `virtual-tradeshow-commercial-v1/`.
2. **Zero-Cost Constraint**: Do not introduce paid cloud services (GPU clusters, paid video APIs, paid DBs) without human sign-off.
3. **Dual Reconstruction Modes**: Clearly differentiate Mode A (Photo Preview) from Mode B (Precision Photogrammetry/Gaussian Splats).
4. **Coordinate Consistency**: Admin 3D Hotspot placement and Buyer 3D Hotspot rendering must use the identical Three.js coordinate system.
5. **Handoff Discipline**: Update `production_artifacts/HANDOFF.md` with every milestone.
