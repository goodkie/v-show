# 04_PHOTO_INPUT_SCHEMA.md — Canonical Booth Source Asset Schema

## 1. Data Schema
```typescript
interface BoothSourceAsset {
  assetId: string;              // Unique UUIDv4
  projectId: string;            // Parent Project ID (e.g. DNA-2026-XXXXXX)
  
  originalFilename: string;     // e.g. "booth_front_center.jpg"
  storagePath: string;          // Logical or absolute storage path
  
  mimeType: string;             // 'image/jpeg' | 'image/png' | 'image/webp'
  fileSize: number;             // Bytes
  
  width: number;                // Pixels
  height: number;               // Pixels
  aspectRatio: number;          // width / height (e.g. 2.0 for 360 equirectangular)
  
  captureDate?: string;         // ISO date
  orientation: number;          // EXIF orientation
  
  sourceType: SourceType;       // REAL_BOOTH_PHOTO | REAL_360_PANORAMA | PROFESSIONAL_RENDER | DESIGNED_VISUAL | PRODUCT_PHOTO | EXISTING_3D | UNKNOWN
  
  isOriginal: boolean;          // true for pristine uploaded raw asset
  isEnhanced: boolean;          // true for derivative generated by enhancement pipeline
  enhancedAssetId?: string;     // Pointer to enhanced derivative
  
  qualityStatus: QualityStatus; // READY | USABLE | DNA_ENHANCEMENT_RECOMMENDED | REPLACEMENT_RECOMMENDED
  processingStatus: ProcStatus; // UPLOADED | VALIDATING | READY | ENHANCING | ENHANCED | BOOTH_GENERATING | PREVIEW_READY | FAILED
  
  uploadedBy: string;           // Customer email or staff user ID
  uploadedAt: string;           // ISO 8601 timestamp
}

enum SourceType {
  REAL_BOOTH_PHOTO = 'REAL_BOOTH_PHOTO',
  REAL_360_PANORAMA = 'REAL_360_PANORAMA',
  PROFESSIONAL_RENDER = 'PROFESSIONAL_RENDER',
  DESIGNED_VISUAL = 'DESIGNED_VISUAL',
  PRODUCT_PHOTO = 'PRODUCT_PHOTO',
  EXISTING_3D = 'EXISTING_3D',
  UNKNOWN = 'UNKNOWN'
}
```

## 2. Truthful Source Labeling Constraints
- `PROFESSIONAL_RENDER` must NEVER be labeled as `REAL_BOOTH_PHOTO`.
- `DESIGNED_VISUAL` must NEVER be labeled as `AUTHENTIC_CAPTURED_3D`.
- Original raw files are preserved permanently; derivatives are generated with source asset traceability (`SOURCE_ASSET_TRACEABILITY = true`).
