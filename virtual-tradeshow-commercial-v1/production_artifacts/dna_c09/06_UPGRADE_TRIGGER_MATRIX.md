# dn’a-C09.06 — Upgrade Trigger Matrix

| Trigger Event | Context | Action |
| :--- | :--- | :--- |
| **Add Second Product** | User clicks `+ Add Another Product` in Free Preview | Opens Plan Modal (`READY TO PUT YOUR BOOTH TO WORK?`) |
| **Publish Attempt** | User clicks `Publish My Booth` | Checks entitlement → Opens Plan Modal |
| **Enable Leads / RFQ** | User clicks `Request RFQ` / `Lead CRM` in drawer | Opens Plan Modal with PRO capability focus |
| **Add More Views** | User requests 360° / Multi-view angles | Opens Plan Modal with BUSINESS capability focus |
| **Explicit Upgrade CTA** | User clicks `Upgrade to Publish` in top banner | Opens Plan Modal |
