# dn’a-C06.20 — Observability & Real-Time Metrics

## 1. System-Wide Production Metrics
- Total Jobs Provisioned
- Active Pipeline Jobs
- Blocked / Action Required Jobs
- Failed Jobs
- Completed / Live Showrooms
- Average Time to First Preview (sec)
- Average Time to Publish (sec)
- Overall System Automation Rate (%)
- Total Operator Touches & Minutes

## 2. Segregation Principle
`INTERNAL_DEV` diagnostics metrics are strictly segregated from commercial customer reporting to prevent metric distortion.
