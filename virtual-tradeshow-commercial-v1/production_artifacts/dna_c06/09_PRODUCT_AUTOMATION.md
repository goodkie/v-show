# dn’a-C06.09 — Product Automation & Completion Levels

## 1. Completion Levels
- **BASIC**: Product Name + Hero Image. (Sufficient for preview and pinpoint binding).
- **STANDARD**: BASIC + Short Description + Category.
- **COMPLETE**: STANDARD + Specs + Wholesale Price + MOQ + PDF Catalog + Video URL.

## 2. Ingest Types
- Manual creation
- Bulk image drag-and-drop
- Catalog AI/OCR extraction (Tagged `EXTRACTED_UNCONFIRMED` until confirmed)
- Existing registry import
