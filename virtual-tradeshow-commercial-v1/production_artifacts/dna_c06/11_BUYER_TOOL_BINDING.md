# dn’a-C06.11 — Buyer Tool Auto-Binding

## Automated Provisioning
Once a product is created in the project registry, the orchestrator automatically binds:
1. **REQUEST_INFO**: Enabled by default for all products.
2. **REQUEST_QUOTE (RFQ)**: Direct inquiry form routed to exhibitor dashboard.
3. **BOOK_MEETING**: Automated appointment scheduling tool.
4. **REQUEST_SAMPLE**: Enabled based on product category & sample availability flag.
5. **DIGITAL_CATALOG**: Auto-compiled downloadable PDF & interactive web catalog.
6. **SMART_EXHIBITOR_CARD**: Auto-linked when representative contact info exists.
7. **PRODUCT_QR**: Generated immediately when stable canonical product slug exists.
