# VALUE MILESTONE SPECIFICATION
**Virtual Trade Show Commercial V1 — Server-Side Telemetry**

---

## 1. Supported Milestone Types
| Milestone Key | Trigger Event | Commercial Meaning |
| :--- | :--- | :--- |
| `booth_created` | Booth initialized | Onboarding milestone |
| `booth_published` | Booth set to active/published | Ready for buyer traffic |
| `first_buyer_view` | First visitor enters booth | First buyer impression |
| `10_buyer_views` | 10 cumulative visitor impressions | Baseline engagement |
| `first_hotspot_click` | Buyer clicks 3D product tag | Product discovery |
| `first_lead` | Buyer submits contact form | Commercial ROI achieved |
| `first_rfq` | Buyer requests formal quotation | High-intent B2B conversion |
| `first_sample_request` | Buyer orders product sample | Evaluation stage |
| `first_appointment` | Buyer books 1:1 meeting | Sales meeting |
| `precision_3d_requested` | Customer requests 3DGS | PRO upgrade readiness |
