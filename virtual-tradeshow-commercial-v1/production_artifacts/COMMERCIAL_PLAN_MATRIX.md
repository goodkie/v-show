## 2. 엔타이틀먼트 초과 시 UX 정책 (Graceful Limit Policy)
- 제품/핫스팟 한도 초과 시: 데이터를 강제로 삭제하거나 부스를 비활성화하지 않고, 새로운 항목 추가 시 `PLAN_LIMIT_REACHED` 구조화 에러와 함께 명확한 업그레이드 안내 모달을 제공합니다.
- 구독 다운그레이드 시: 기존에 등록된 제품이나 수집된 리드는 안전하게 보존되며, Free 플랜 범위 내에서 지속해서 열람 가능합니다.
