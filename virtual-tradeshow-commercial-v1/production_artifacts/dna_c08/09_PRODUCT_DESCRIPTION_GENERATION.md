# dn’a-C08.09 — AI Product Description Assist & Safety

## Generation Rules
1. **Suggested / Draft Only**: Generated descriptions are placed into an editable textarea with clear badge `[Suggested Draft — Review before publishing]`.
2. **Context-Aware**: Ingests `productName`, `category`, and `businessName`.
3. **Safety & Zero Hallucinations**:
   - Strictly avoids fabricating technical dimensions, voltage, certifications (CE, FDA, ISO), MOQ, pricing, or unverified claims.
   - Highlights visual elegance, commercial presentation, and key buyer value propositions.
