이메일 작성

개인정보 보호를 위해 외부 이미지 자동 요청은 기본 차단됩니다. 체크하면 이미지 호스트에 접속 정보가 전달될 수 있습니다. HTML 내보내기에는 입력한 이미지 URL을 유지합니다.
이미지 파일은 PC 내 미리보기만 지원합니다. 실제 발송용 HTML에는 공개 HTTPS 이미지 URL을 입력해야 합니다. 이메일 본문의 링크만으로 RFC 8058 원클릭 구독 취소 헤더가 생성되는 것은 아닙니다. 해당 헤더와 작동하는 POST 엔드포인트는 발송 서비스에서 별도 검증해야 합니다.
