## 1. 통합 압축파일 구성 및 버전 구분

XPIDER V7.1.0 패키지는 **보안 분리 원칙**에 따라 두 가지 통합 압축파일로 제공됩니다.

| 구분 | 공개 GitHub 클린 통합 압축파일 (`ALL_IN_ONE_BUNDLE`) | 본인 전용 로컬 통합 압축파일 (`PERSONAL_ALL_IN_ONE_LOCAL_ONLY`) |
|---|---|---|
| **포함 내용** | 클린 설치 EXE + 클린 포터블 ZIP + SHA-256 검증파일 + 설치·총사용법 가이드(`.html`/`.md`) | 개인 키·설정 내장 설치 EXE + 개인 포터블 ZIP + 설치·총사용법 가이드(`.html`/`.md`) + 보안 주의서 |
| **API 키 / OAuth 포함 여부** | ❌ **완전 미포함** (`ZERO SECRETS` · 공개 배포용) | ✅ **12개 개인 설정·키·재암호화 가능 DPAPI OAuth 포함** |
| **GitHub 업로드 가능 여부** | ✅ 가능 (공식 GitHub Releases 배포본) | ⛔ **절대 금지** (본인 PC·USB·비공개 드라이브 전용) |
| **용도** | 공개 배포 · 기존 설치 PC의 GitHub 자동 업데이트 | **새 Windows PC로 1번에 내 모든 설정·키 그대로 이전 설치** |

### 설치 후 폴더 구조 (`%LOCALAPPDATA%\XPIDER\`)
- **`%LOCALAPPDATA%\XPIDER\App\`** *(프로그램 본체 — 업데이트 시 교체됨)*
  - `extension\` : Chrome / Edge에 로드하는 MV3 확장 프로그램 폴더 (고정 ID `ldlijlaccfeelfdhgnjbibniocefckjj`)

  - `companion\` : 로컬 Email Sidecar(`127.0.0.1:18990`) 및 Native Messaging Host 모듈
  - `START_EMAIL_TEST_SIDECAR.bat` / `STOP_EMAIL_TEST_SIDECAR.bat` / `CHECK_EMAIL_TEST_SIDECAR.bat` : 로컬 Sidecar 수동 시작·종료·상태 확인 배치 파일

  - `XPIDER_V7.1.0_설치방법_및_총사용법_가이드.html` / `.md` : 본 설명서

## 2. 최신 버전 설치 방법

> **중요**: Chrome 확장 폴더(`extension\`)만 복사해서 로드하면 이메일 발송·Sidecar 기능이 작동하지 않습니다. 반드시 아래 통합 설치기(`.exe`)를 1회 실행해 로컬 런타임과 Native Messaging Host를 등록해 주세요.

### 방법 A. 새 Windows PC 처음 설치 — 본인 전용 로컬 설치기 (모든 키·OAuth 자동 복원)
본인이 쓰는 다른 Windows 10/11 PC로 모든 설정을 그대로 옮길 때 가장 빠릅니다.

1. **`XPIDER_V7.1.0_PERSONAL_ALL_IN_ONE_LOCAL_ONLY_<해시>.zip`** 압축을 풉니다.
2. **`XPIDER_V7.1.0_PERSONAL_LOCAL_ONLY_<해시>.exe`** 를 더블클릭합니다.
   - Windows SmartScreen("Windows의 PC 보호") 창이 뜨면 **`추가 정보`** → **`실행`**을 클릭합니다. (`UNSIGNED` 개인 빌드이기 때문입니다.)
3. 설치 창 제목에 `[PERSONAL LOCAL-ONLY]`가 표시되는지 확인하고 **`설치 / 업그레이드 (Install / Upgrade)`** 버튼을 클릭합니다.
4. 설치가 진행되면서 다음 작업이 자동으로 완료됩니다:
   - `%LOCALAPPDATA%\XPIDER\App`에 앱·내장 `node.exe`·확장 프로그램 설치
   - Chrome / Edge Native Messaging Host(`com.xpider.email_sidecar`) 자동 등록
   - **12개 개인 설정·API 키·이미지 호스팅·수신거부 차단 원장·Gmail 웹 작성창 계정 목록 자동 복원**
   - **Gmail OAuth Client 및 연결 계정 Refresh 토큰을 새 PC의 Windows DPAPI로 자동 재암호화**
   - 로컬 Email Sidecar(`127.0.0.1:18990`) 자동 기동 및 확장 폴더 경로 클립보드 자동 복사
5. Chrome(또는 Edge) 주소창에 **`chrome://extensions`** 를 입력해 엽니다.
6. 우측 상단 **`개발자 모드`** 스위치를 **ON**으로 켭니다.
7. 좌측 상단 **`압축해제된 확장 프로그램을 로드합니다`** 를 클릭하고 **`%LOCALAPPDATA%\XPIDER\App\extension`** 폴더를 선택합니다.
   - 확장 프로그램 ID가 **`ldlijlaccfeelfdhgnjbibniocefckjj`** 로 고정 표시되면 설치 완료입니다!
8. *(Gmail 웹 작성창 발송 사용 시)* 새 PC의 Chrome 프로필에서 발신에 사용할 본인 Google 계정들을 **Google [계정 추가]**로 로그인해 둡니다.

### 방법 B. 새 Windows PC 처음 설치 — 공개 GitHub 클린 설치기 (키 미포함)
1. **`XPIDER_V7.1.0_ALL_IN_ONE_BUNDLE_<해시>.zip`** 압축을 풀고 **`XPIDER_V7.1.0_SETUP_<해시>.exe`** 를 실행합니다.
2. 설치 완료 후 `chrome://extensions` (개발자 모드 ON) → **`%LOCALAPPDATA%\XPIDER\App\extension`** 폴더를 로드합니다.
3. Email Studio를 연 뒤 필요한 API 키(Resend / Gemini / 이미지 호스팅 / Gmail OAuth)와 발신 Gmail 계정을 직접 입력해 사용합니다.

### 방법 C. 포터블 ZIP(`PORTABLE`)으로 폴더에서 직접 사용하기
1. 포터블 ZIP을 원하는 폴더(예: `C:\XPIDER_PORTABLE`)에 압축 해제합니다.
2. *(로컬 전용 포터블 ZIP을 새 PC에 옮긴 경우)* 폴더 안의 **`APPLY_PERSONAL_SETTINGS.bat`** 를 1회 실행해 개인 설정·DPAPI를 복원합니다.
3. **`START_EMAIL_TEST_SIDECAR.bat`** 를 실행해 로컬 Sidecar(`18990`)를 켭니다.
4. `chrome://extensions` (개발자 모드 ON) → 압축 해제한 폴더 안의 **`extension`** 폴더를 로드합니다.

### 방법 D. 이미 XPIDER가 설치된 PC에서 최신 버전으로 업그레이드
- **가장 쉬운 방법 (1클릭 자동 업데이트)**:
  1. Email Studio 맨 위 파란색 **`🔄 최신 업데이트 확인`** 버튼 클릭
  2. 새 버전이 감지되면 **`⬇️ 최신 버전 다운로드 후 설치`** 클릭 (SHA-256 무결성 검증 자동 수행 · 기존 API 키/OAuth/계정/수신거부 100% 보존)
  3. 완료 안내가 뜨면 **`chrome://extensions`** 에서 XPIDER 카드의 **새로고침(🔄)** 아이콘 클릭!
- **수동 업그레이드**:
  - 기존 확장을 삭제하지 말고 새 `XPIDER_V7.1.0_SETUP_<해시>.exe`를 덮어쓰기 설치한 뒤 `chrome://extensions`에서 **새로고침(🔄)** 하세요. (기존 확장 삭제 후 로드할 경우에도 `%LOCALAPPDATA%\XPIDER\Sidecar`의 모든 키·계정·원장은 그대로 보존됩니다.)

## 3. 총사용법 Part 1 — AutoForm 자동 폼 전송

Chrome 우측 상단 툴바에서 **XPIDER 아이콘**을 클릭하면 사이드 패널(`popup.html`)이 열립니다.

1. **기본 입력 프로필 설정**: 회사명, 담당자 이름, 이메일, 전화번호, 웹사이트, 문의 메시지 등 폼에 자동 입력할 항목을 입력합니다.
2. **대상 URL 목록 입력**: 1줄에 1개씩 대상 웹사이트 URL을 붙여넣거나 CSV/파일로 불러옵니다.
3. **실행 모드 선택**:
   - **AUTO (자동)**: 폼 탐지 → 입력 → 전송 및 결과 확인까지 자동 실행
   - **SEMI_AUTO (반자동)**: 필수 입력값 누락·캡차·확인 필요 시 페이지 내 반자동 패널에서 일시 정지해 운영자가 직접 확인 후 완료 버튼 클릭
   - **메시지 칸 없는 폼 포함(Opt-In)**: 기본 꺼짐. 체크 시 뉴스레터/단순 문의처럼 메시지 `<textarea>`가 없는 적격 폼도 포함 (로그인·검색·결제·비동의 폼은 항상 제외)
4. **제어 버튼**: **`시작`** / **`일시중지`** / **`이어서(재개)`** / **`중지`** 지원. 브라우저를 닫았다 켜도 일시중지 체크포인트와 히스토리 원장이 유지됩니다.
5. **Privacy Relay 프록시 (`18988/18989`) 주의사항**:
   - AutoForm에서 프록시/릴레이를 켠 상태라면 Gmail 웹 작성창 접속 시 `502 Bad Gateway` 또는 Google 보안 경고가 뜰 수 있습니다.
   - Email Studio의 Gmail 웹 작성창 패널에서 프록시 경고 배너가 뜨면 **`🔓 브라우저 프록시 해제 (Gmail 직접 연결로 전환)`** 버튼을 1회 클릭하세요.
6. **Email Studio 열기**: 사이드 패널 상단의 **Email Studio** 링크를 클릭하면 전체 화면 이메일 발송 스튜디오가 열립니다.

## 4. 총사용법 Part 2 — Email Template Studio 작성 · 실시간 미리보기 · 직접 편집

### 4-1. 좌측 이메일 작성 패널
- **메시지 종류**: `업무 / 서비스 안내` 또는 `마케팅 / 뉴스레터 (수신 동의 필수)` 선택 (마케팅 선택 시 사업자 우편주소 및 RFC 8058 수신거부 푸터가 자동 연계됨)
- **제목 / 미리보기 문구(Preheader) / 발신 브랜드 / From 표시 이름**: 수신함에 표시되는 보낸사람 이름과 제목을 입력합니다.
- **본문**: 빈 줄(엔터 2번)로 문단을 구분합니다. 수신자 이름이 있으면 `{{name}}` 치환 태그를 사용할 수 있습니다.
- **이미지 첨부 (로컬 미리보기 & 공개 HTTPS 자동 업로드)**:
  1. `이미지 파일 선택`으로 PC의 PNG/JPG/WebP/GIF(3MB 이하) 선택 → 즉시 로컬 미리보기 확인
  2. 실제 메일 발송에 이미지를 넣으려면 **`☁️ 로컬 이미지 공개 HTTPS 업로드 → 자동 삽입`** 에서 동의 체크 후 **`🖼️ 이미지 업로드 및 자동 삽입`** 클릭 (GitHub 공개 저장소 또는 Cloudflare R2/HTTPS PUT 지원) → 공개 HTTPS URL 자동 입력 및 익명 GET 검증 완료
  3. 개인정보 보호를 위해 `외부 HTTPS 이미지 미리보기 로딩 허용`은 기본 해제되어 있으며, 필요 시 체크해 미리보기에서 이미지를 확인할 수 있습니다.
- **버튼 문구 & HTTPS 링크 / 회신 이메일(Reply-To) / 사업자 우편주소** 입력
- **구독 취소(수신 거부) 자동 삽입 (RFC 8058)**: 공개 HTTPS 수신거부 기본 URL을 저장하면 실제 발송 시 수신자별 고유 서명 토큰 URL과 `List-Unsubscribe-Post` 원클릭 헤더가 자동 삽입됩니다.
- **내보내기 · 불러오기 · 캠페인 통째로 저장**:
  - `HTML 저장` / `텍스트 저장` / `템플릿 JSON` / `🌐 HTML 불러오기(.html/.htm)` / `💾 초안 저장` / `⭐ 템플릿 라이브러리`
  - **`📦 전체 캠페인 저장 · 불러오기`**: 제목·본문·이미지·링크·수신자 CSV·SME 필터·A/B안·스팸방지 옵션·Gmail/Resend 공급자 설정·미리보기 직접 편집 내용을 **통째로** 로컬 Sidecar NTFS 보안 파일에 저장하고 1클릭 복원하거나 `.json` 파일로 내보낼 수 있습니다 (API 키·OAuth 토큰·최종 발송 동의 체크는 보안상 제외됨).

### 4-2. 우측 실시간 미리보기 · 직접 편집 (3가지 모드)
상단 탭에서 언제든 3가지 모드를 전환할 수 있으며, `데스크톱` / `모바일` 폭 전환 버튼이 모든 모드에 적용됩니다.

1. **`👁️ HTML 미리보기`**:
   - 완전 격리된 `sandbox=""` 보안 iframe으로 실제 HTML 이메일 렌더링을 확인합니다.
2. **`✏️ HTML 직접 편집`**:
   - **`🎨 시각적 편집`**: 미리보기 화면 본문을 클릭해 바로 타이핑하고, 상단 도구모음(**B**, *I*, U, 목록, `🔗 HTTPS 링크`, 서식 지우기)으로 직접 편집합니다.
   - **`</> HTML 소스`**: HTML 코드를 직접 수정합니다.
   - 수정 즉시 HTML 미리보기·발송 본문에 반영되며, `<script>`·위험 태그는 자동 차단됩니다. 언제든 **`🔄 기본 에디터 HTML 복원`** 으로 되돌릴 수 있습니다.
3. **`📝 Gmail 텍스트 미리보기·편집` (Gmail 선택 시 자동 전환!)**:
   - 하단 **`발송 공급자 선택`**에서 **`Gmail API (...)`** 를 선택하면 미리보기가 자동으로 이 탭으로 전환됩니다.
   - 이모지 5개 이상·영문 전체 대문자 3줄 이상·강한 할인/느낌표 밀집이 감지되면 **차분한 텍스트 기반 이메일로 자동 변환된 제목과 본문**이 실시간 표시됩니다.
   - 제목과 본문을 직접 수정하면 **`✏️ 사용자 직접 편집 적용 중`** 으로 잠금 보호되어 Gmail 웹 작성창/Gmail API 발송 시 수정된 내용이 그대로 사용됩니다.
   - 하단 고정 영역에는 발송 시 자동 부착되는 물리적 주소 및 수신거부 푸터가 표시됩니다.
   - **`🔄 자동 변환 원본으로 복원`** / **`⬅️ 좌측 기본 에디터에 반영`** / **`📋 텍스트 본문 복사`** 버튼 제공.

### 4-3. 콘텐츠 품질(Gemini AI) & 통합 스팸방지 체크리스트
- **규칙 기반 문구 교정 제안**: 맞춤법·과장 표현·연속 느낌표 등을 점검해 원문 대비 비교 후 수락/거절할 수 있습니다.

  - **`🔍 통합 스팸 위험도 · 체크리스트 진단`**: 0~100점 위험도(`LOW_RISK` / `MEDIUM_RISK` / `HIGH_RISK`)와 자동(AUTO)·반자동(SEMI-AUTO)·수동(MANUAL) 항목별 상태를 진단합니다.

5. **적법 발송 권한 & A/B 테스트**:
   - **`이 수신리스트에 대한 적법한 발송 권한을 확인했습니다`** 체크 및 적법 근거/관할/출처 입력 후 **`드라이런 실행 (발송 없음)`**으로 사전 점검할 수 있습니다.

## 6. 총사용법 Part 4 — [기본·권장] Gmail 웹 작성창 다계정 안전 대량발신

하단 **`발송 공급자 선택 (Email Delivery Provider)`**에서 **`Gmail API (소유자 승인 OAuth PKCE · 단일/복수 계정)`**을 선택하면 기본값으로 **`✉️ Gmail 웹 작성창 다계정 직접 발송`**이 활성화됩니다.

> **왜 이 방식이 기본인가요?**  
> 미검증 OAuth 앱 API 시그니처를 회피하고 Google 공식 웹 작성창(`mail.google.com`)에서 운영자가 직접 `Ctrl+Enter`로 발송하므로 스팸 분류 및 계정 일괄 정지 위험을 크게 낮춥니다. (DOM 스크래핑·Send 버튼 자동 클릭 봇은 계정 정지 방지를 위해 의도적으로 배제했습니다.)

### 단계 1: 본인 소유 구글 발신 계정 다중 등록 · 슬롯 · 워밍업 단계 설정
1. 발신에 사용할 Google 계정들은 **현재 사용 중인 같은 Chrome 프로필**에서 Google [계정 추가]로 모두 로그인되어 있어야 합니다.
2. **`1) 본인 소유 구글 발신 계정 다중 등록`**에서 이메일·별칭·Chrome 슬롯(`자동전환` 권장 또는 `u/0`..`u/9`)·초기 워밍업 단계를 고르고 **`➕ 발신 계정 등록 / 갱신`**을 클릭합니다.
3. 등록된 각 계정 행에서 바로 조정할 수 있는 컨트롤:
   - **체크박스**: 이번 캠페인에 참여시킬 계정 선택
   - **1클릭 숙성·워밍업 단계 드롭다운**:
     | 단계 | 개인 `@gmail.com` (1계정) | Google Workspace (1계정) |
     |---|---|---|
     | **`워밍업`** *(기본 · 신규 1~2주)* | 일 **15통** (1시간 5통 · 90초 간격) | 일 **40통** (1시간 12통 · 60초 간격) |
     | **`안정화`** *(3~4주차)* | 일 **30통** (1시간 10통 · 60초 간격) | 일 **100통** (1시간 25통 · 45초 간격) |
     | **`숙성`** *(오래된 계정)* | 일 **80통** (1시간 20통 · 45초 간격) | 일 **300통** (1시간 50통 · 30초 간격) |
   - **Chrome 슬롯 드롭다운 (`자동전환` / `u/0`..`u/10`)**: `자동전환`은 Google 공식 `AccountChooser`로 계정을 정확히 선택합니다. 특정 슬롯 번호를 알고 있으면 `u/0`, `u/1` 등으로 바로 지정할 수 있습니다.
   - **`🔍 계정 확인`**: 해당 계정이 Chrome에 정상 로그인되어 있는지와 `/mail/u/N/` 슬롯 번호를 즉시 확인합니다.
   - **`🗑️ 삭제`**: 풀에서 계정 제거.

### 단계 2: 다계정 고정 배정 · 수동 1건씩 열기
1. 수신자 CSV(상단) 또는 **`빠른 수신자 직접 입력`** 칸에 수신자 이메일을 입력합니다.
2. 노란색 박스 **`[필수] 위 수신자에 대해 적법한 발송 권한을 확인했습니다`** 를 체크합니다.
3. `서명된 수신거부 HTTPS 링크 자동 삽입` 체크 여부를 확인합니다 (미체크 시 회신 수신거부 문구 자동 삽입).
4. **`📋 1단계: 다계정 안전 큐 배정 · 다일 일정 계산`** 으로 교차 수신거부 제외·고정 계정 배분·소요일을 먼저 확인하거나, 바로 파란색 **`✉️ 2단계: Gmail 작성창 열기 (미배정 시 자동 배정 후 열기)`** 를 클릭합니다.
5. 열린 Gmail 탭에서 내용 확인 후 **`Ctrl+Enter`(발송) → `Ctrl+W`(탭 닫기)** 합니다.
   - 이미지나 서식 HTML을 넣고 싶다면 **`📋 이미지·서식 본문 복사 (작성창 Ctrl+V용)`** 을 누른 뒤 Gmail 작성창 본문에 `Ctrl+V` 하세요.
   - Gmail에서 발송 경고·제한 메시지가 뜨면 즉시 **`🛑 경고/반송 감지 → 전체 안전 일시중지`** 를 누르세요 (경고 계정 24시간 보호 쿨다운 + 한도 50% 감속, 타 계정 우회 금지).

### 단계 3: ⏱️ 사람 패턴 랜덤 인터벌 자동 페이싱 스케줄러 (반자동 대량발송)
계정 정지를 최대한 방지하면서 편하게 연속 발송하려면 **`3) 사람 패턴 랜덤 인터벌 · 자동 휴식 · 일일 한도 페이싱 스케줄러`** 를 사용합니다.

1. 설정값 조정:
   - **최소 / 최대 랜덤 간격 (초)**: 예 `60 ~ 180초` (최소 30초 하한 강제, 삼각 분포로 매번 사람처럼 다른 간격 적용)
   - **자연 휴식 주기 / 휴식 시간**: 예 `6통마다 6분(±25% 랜덤)` 자동 휴식
   - **주간 발송 시간대만 진행 (`9시 ~ 19시`)**: 기본 체크됨.  
     > 💡 **야간/새벽에 바로 테스트하거나 발송하려면 이 체크박스를 잠시 해제하세요!**
   - **Gmail 탭 닫힘(`Ctrl+Enter → Ctrl+W`) 감지 시 완료 기록 후 다음 랜덤 대기 자동 시작**: 기본 체크됨.
2. **`▶️ 랜덤 인터벌 자동 페이싱 시작`** 클릭 → 첫 번째 Gmail 작성창이 열립니다.
3. 대표님은 열린 Gmail 탭에서 **`Ctrl+Enter` → `Ctrl+W`** 만 누르시면 자동으로 발송 완료가 기록되고 다음 랜덤 카운트다운 후 다음 작성창이 열립니다.
4. 중단하려면 **`⏸️ 자동 페이싱 일시중지`** 를 누르세요.

### 단계 4: 📊 실시간 전체 리스트 모니터 · 삭제 · 마스터 보내기 히스토리 리셋
- **계정별 실시간 게이지**: 각 계정의 `1분 / 1시간 / 24h` 사용량과 진행률 바가 표시되며, 쿨다운 중일 때는 **1초마다 실시간 카운트다운** 후 만료 즉시 `🟢 즉시 발송 가능`으로 자동 전환됩니다.
- **전체 수신자 상태 테이블**: 상태 필터(`전체 / 대기 / 작성창 열림 / 발송 완료 / 건너뜀·제외`)와 각 행별 **`🔁 다시 열기` · `↩️ 대기 복구` · `✅ 완료` · `⏭️ 건너뛰기` · `🗑️ 삭제`** 버튼 제공.
- **`🧹 마스터 보내기 히스토리 리셋`**:
  - 같은 수신자에게 다시 테스트/재발송하려는데 `♻️ 기발송 제외 (ALREADY_SENT_IN_CAMPAIGN)`로 막힐 때 사용합니다.
  - 캠페인 중복 방지 기억과 현재 대기열을 깨끗하게 초기화합니다 (옆 체크박스 선택 시 로컬 1분/1시간/24시간 테스트 카운터도 함께 0으로 초기화).

## 7. 총사용법 Part 5 — Gmail API OAuth 자동 발송 & Resend 상용·2차 발송

### 7-1. Gmail API OAuth 자동 발송 (Google Workspace 맞춤 도메인 권장)
`Gmail 발송 수단 선택`에서 **`⚙️ Gmail API OAuth 자동 발송`** 으로 전환하면 하위 패널이 표시됩니다.
1. **Google Cloud OAuth 2.0 Desktop Client 설정**: Client ID / Secret 입력 → 동의 체크 → **`🔐 OAuth Client 로컬 저장`** (Windows DPAPI 암호화) → **`🔗 Gmail 계정 연결 (OAuth PKCE)`** 로 본인 계정 승인 (최소 권한 `gmail.send`만 요청).
2. **브랜드 도메인 · 수신거부 도메인 통일 설정**: 본인 브랜드 도메인과 수신거부 HTTPS URL을 저장하고 **`🔍 브랜드 SPF/DMARC · 수신거부 DNS/HTTPS 점검`** 으로 정렬 상태를 확인합니다.
3. **1통 셀프 테스트** → **`🛡️ 발신 위생 점검`** → **다일 안전 분산 큐 배정 및 발송 실행**.
   - `401 / 403 / 429` 또는 롤링 한도 도달 시 타 계정 우회 없이 전체 캠페인이 즉시 안전 일시중지됩니다.

### 7-2. Resend 발송 (인증 도메인 운영 · 시뮬레이터 · 2차 미오픈 발송)
`발송 공급자 선택`에서 **`Resend`** 를 선택합니다.
1. **Sidecar 연결 및 Resend API 키 저장**: `🔗 원클릭 자동 페어링`으로 연결 확인 → `re_...` API 키 입력 및 동의 체크 → **`🔑 NTFS 보안 저장 후 상태 확인`**.
2. **🧪 시뮬레이터 테스트 발송**: `delivered@resend.dev` / `bounced@resend.dev` / `complained@resend.dev`로 안전 테스트 (실제 고객 미발송).
3. **📨 실제 테스트 이메일 1통 보내기**: 본인 승인 수신함 1곳에 실제 테스트 메일 발송 및 상태(`ACCEPTED` vs `DELIVERED`) 확인.
4. **🚀 상용(운영) 대량발송**: 캠페인 ID 확인(새 캠페인은 `🆕 새 캠페인 ID 생성`) → 적법 발송 권한 체크 → **`🔍 운영 DNS · 동의확인 · 수신거부 · 웹훅 점검`** → **`🚀 대량발송 시작`**.
5. **실시간 캠페인 모니터 & 2차 미오픈 발송**:
   - `🔄 진행률 새로고침` / `🔎 Resend 이력 대조` / `⏱️ 자동 폴링 켜기`로 접수·전달·오픈·클릭·반송·수신거부 현황을 추적합니다.
   - 기준 시간(예: 24시간) 경과 후 **`🔍 2차 발송 미리보기`** → **`🚀 2차 발송 — 미오픈 대상만`** 으로 반송·신고·수신거부 대상을 자동 제외한 후속 발송이 가능합니다.

## 8. 앱 내 1클릭 GitHub 최신 업데이트 & 안전한 백업/제거

### 앱 내 1클릭 업데이트 (기존 키·계정 100% 보존)
1. Email Studio 상단 헤더 우측 **`🔄 최신 업데이트 확인`** 클릭
2. 새 릴리스가 있으면 **`⬇️ 최신 버전 다운로드 후 설치`** 클릭
3. 로컬 Sidecar가 공식 GitHub 릴리스 자산만 다운로드하고 `.sha256.txt`와 **SHA-256 해시를 검증**한 뒤 설치기를 자동 실행합니다 (해시 불일치 시 즉시 삭제·차단).
4. 설치 완료 후 Chrome `chrome://extensions`에서 XPIDER **새로고침(🔄)** 을 누릅니다.

### 안전한 제거 (`UNINSTALL_XPIDER.bat`)
- `%LOCALAPPDATA%\XPIDER\App\UNINSTALL_XPIDER.bat` 실행 시 기본 옵션(`--retain-data`)으로 프로그램 파일과 레지스트리만 제거하며, **`%LOCALAPPDATA%\XPIDER\Sidecar`의 사용자 데이터·수신거부 원장·이력은 안전하게 보존**합니다.
- 모든 데이터까지 완전히 지우려면 설치기 UI에서 `제거 시 사용자 데이터 보존` 체크를 해제한 뒤 제거하세요.

## 10. 컴플라이언스 · 계정 보호 및 정직한 고지

- **발송 권한 및 수신거부 준수**: 무단 수집/스크래핑/구매 목록에 대한 발송은 금지되며, 수신거부(Opt-Out) 차단 원장은 Resend·Gmail 웹 작성창·Gmail API 간에 교차 적용되고 마스터 리셋 시에도 영구 보존됩니다.
- **정직한 도달률 고지**: Gmail 웹 작성창 발송, 자동 텍스트형 변환, 인라인 CID, 랜덤 인터벌 페이싱은 스팸 분류 및 계정 정지 위험을 낮추기 위한 정당한 발신 위생 도구이지만, **100% 기본 받은편지함(Primary) 배치나 계정 정지 면제를 보장하지 않습니다.**
- **로컬 전용 개인 빌드 보안 주의**: `LOCAL_PRIVATE_ONLY` 폴더 안의 개인 통합 설치기·압축파일에는 대표님의 실제 API 키와 OAuth 설정이 포함되어 있으므로 **절대로 GitHub, 공개 클라우드, 메신저 등에 업로드하지 마시고 본인 소유 기기 간 이동에만 사용하세요.**
