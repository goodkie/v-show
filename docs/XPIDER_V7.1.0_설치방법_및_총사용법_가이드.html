중요 안내: extension\ 폴더만 복사해 Chrome에 로드하면 이메일 발송·Sidecar 기능이 작동하지 않습니다. 반드시 아래 통합 설치기(.exe)를 1회 실행해 내장 Node 런타임과 Native Messaging Host를 등록해 주세요.

방법 A. 새 Windows PC 처음 설치 — 본인 전용 로컬 설치기 (권장 · 모든 키·OAuth 자동 복원)

  1. 1XPIDER_V7.1.0_PERSONAL_ALL_IN_ONE_LOCAL_ONLY_<해시>.zip 압축을 풉니다.
  2. 2XPIDER_V7.1.0_PERSONAL_LOCAL_ONLY_<해시>.exe 를 실행합니다. (Windows SmartScreen 창이 뜨면 추가 정보 → 실행 클릭)
  3. 3창 제목의 [PERSONAL LOCAL-ONLY] 표시를 확인하고 설치 / 업그레이드 (Install / Upgrade) 버튼을 클릭합니다.
  4. 4설치가 끝나면 아래 항목이 자동으로 완료됩니다:
    • 앱 + 내장 node.exe 설치 및 Chrome/Edge Native Messaging Host 자동 등록
    • 12개 개인 설정·API 키·이미지 호스팅·수신거부 원장·Gmail 웹 작성창 계정 자동 복원
    • Gmail OAuth Client 및 연결 계정 Refresh 토큰을 새 PC의 Windows DPAPI로 자동 재암호화
    • 로컬 Email Sidecar(18990) 자동 기동 및 확장 폴더 경로 클립보드 복사
  5. 5Chrome(또는 Edge) 주소창에 chrome://extensions 입력 → 우측 상단 개발자 모드 ON
  6. 6좌측 상단 압축해제된 확장 프로그램을 로드합니다 클릭 → %LOCALAPPDATA%\XPIDER\App\extension 선택 (고정 ID ldlijlaccfeelfdhgnjbibniocefckjj 확인)
  7. 7Gmail 웹 작성창 발송을 사용할 Google 계정들을 같은 Chrome 프로필의 Google [계정 추가]로 로그인합니다.

방법 B. 새 Windows PC 처음 설치 — 공개 GitHub 클린 설치기 (키 미포함)

방법 C. 포터블 ZIP(PORTABLE) 수동 사용

3. 총사용법 Part 1 — AutoForm 자동 폼 전송 (Side Panel)

Chrome 우측 상단 XPIDER 아이콘을 클릭하면 사이드 패널(popup.html)이 열립니다.

  1. 기본 입력 정보 입력: 회사명, 담당자명, 이메일, 전화번호, 웹사이트, 문의 메시지를 입력합니다.
  2. 대상 URL 목록 입력: 한 줄에 한 개씩 URL을 입력하거나 CSV/텍스트 파일을 불러옵니다.
  3. 실행 모드 선택:
    • AUTO (자동): 문의 폼 탐지 → 자동 입력 → 제출 및 완료 검증까지 연속 실행
    • SEMI_AUTO (반자동): 필수 입력 누락·캡차·확인 필요 시 일시 정지해 운영자가 확인 후 수동 완료 처리
    • 메시지 칸 없는 폼 포함(Opt-In): 기본 꺼짐. 체크 시 단순 문의/구독형 적격 폼도 포함 (로그인·검색·결제·비동의 폼은 항상 제외)
  4. 일시중지 · 재개 · 복원: 작업 중 일시중지/중지 후 브라우저를 재시작해도 체크포인트와 발송 이력 원장이 유지됩니다.
  5. Email Studio 열기: 사이드 패널 상단의 Email Studio 버튼을 클릭하면 이메일 발송 전용 스튜디오가 새 탭으로 열립니다.

4. 총사용법 Part 2 — Email Template Studio 작성 · 실시간 미리보기 · 직접 편집

4-1. 좌측 이메일 편집기 & 캠페인 관리

  • 메시지 종류: 업무/서비스 안내 또는 마케팅/뉴스레터(수신 동의 필수) 선택
  • 제목 · 미리보기 문구 · 발신 브랜드 · From 표시 이름 · 본문 입력 (빈 줄로 문단 구분, {{name}} 이름 치환 지원)
  • 이미지 업로드 및 자동 삽입: PC 이미지(PNG/JPG/WebP/GIF, 3MB 이하) 선택 → 공개 업로드 동의 체크 → 🖼️ 이미지 업로드 및 자동 삽입 클릭 시 공개 HTTPS URL이 자동 입력·검증됩니다.
  • RFC 8058 원클릭 수신거부 자동 관리: 공개 HTTPS 수신거부 기본 URL이 설정되어 있으면 실제 발송 시 수신자별 고유 서명 토큰 링크와 List-Unsubscribe-Post 헤더가 자동 부착됩니다.
  • 📦 전체 캠페인 저장 · 불러오기: 제목·본문·이미지·수신자 CSV·SME 필터·A/B안·스팸방지 옵션·Gmail/Resend 설정·미리보기 직접 편집 내용을 통째로 로컬 Sidecar NTFS 보안 파일에 저장/복원하거나 JSON 파일로 내보낼 수 있습니다.

2단계: 다계정 고정 배정 · Gmail 작성창 열기

  1. 상단 수신자 CSV 또는 빠른 수신자 직접 입력 칸에 수신자 이메일을 입력하고 노란색 [필수] 적법 발송 권한 확인을 체크합니다.
  2. 📋 1단계: 다계정 안전 큐 배정으로 교차 수신거부 제외·고정 계정 배정·예상 소요일을 확인하거나, 바로 파란색 ✉️ 2단계: Gmail 작성창 열기를 누릅니다.
  3. 열린 Gmail 탭에서 내용 확인 후 Ctrl+Enter(발송) → Ctrl+W(탭 닫기)를 누릅니다. (이미지·서식 본문이 필요하면 📋 이미지·서식 본문 복사 후 작성창에 Ctrl+V)
  4. 경고·제한 메시지가 보이면 즉시 🛑 경고/반송 감지 → 전체 안전 일시중지를 누릅니다 (경고 계정 24시간 보호 쿨다운 + 50% 감속, 타 계정 우회 금지).

3단계: ⏱️ 사람 패턴 랜덤 인터벌 자동 페이싱 스케줄러

  • 랜덤 간격(삼각 분포): 최소~최대 초(예: 60~180초, 최소 30초 하한 강제) 사이에서 매번 사람형 랜덤 간격을 계산합니다.
  • 자연 휴식 주기: 설정한 통수(예: 6통)마다 6분(±25% 랜덤) 자동 휴식을 넣습니다.
  • 주간 발송 시간대만 진행 (9시 ~ 19시): 기본 체크됨. 야간·새벽에 바로 테스트/발송하려면 이 체크를 잠시 해제하세요!
  • 탭 닫힘 자동 감지: ▶️ 랜덤 인터벌 자동 페이싱 시작을 누른 뒤 열린 Gmail 탭에서 Ctrl+Enter → Ctrl+W만 누르면 완료 기록 후 자동으로 다음 랜덤 타이머가 시작됩니다.

4단계: 📊 실시간 전체 리스트 모니터 · 삭제 · 마스터 보내기 히스토리 리셋

  • 계정별 1분/1시간/24h 게이지: 쿨다운 중일 때 1초마다 실시간 카운트다운 후 만료 시 자동으로 🟢 즉시 발송 가능으로 복구됩니다.
  • 행별 제어: 🔁 다시 열기 · ↩️ 대기 복구 · ✅ 완료 · ⏭️ 건너뛰기 · 🗑️ 삭제 지원.
  • 🧹 마스터 보내기 히스토리 리셋: 이전 발송 기록(ALREADY_SENT_IN_CAMPAIGN)으로 막힌 목록을 처음부터 다시 테스트/발송할 때 사용합니다. 선택 체크 시 로컬 테스트 카운터도 함께 0으로 초기화되며, 등록 계정과 교차 수신거부(Opt-Out) 차단 원장은 영구 보호됩니다.

7. 총사용법 Part 5 — Gmail API OAuth 자동 발송 & Resend 상용·2차 발송

7-1. Gmail API OAuth 자동 발송 (Google Workspace 맞춤 도메인 권장)

  • Gmail 발송 수단 선택 → ⚙️ Gmail API OAuth 자동 발송 선택.
  • Google Cloud Desktop OAuth Client ID/Secret을 Windows DPAPI에 저장 후 🔗 Gmail 계정 연결 (OAuth PKCE) (최소 권한 gmail.send).
  • 🌐 브랜드 도메인 · 수신거부 도메인 통일 설정 저장 및 DNS(SPF/DMARC/CNAME) 점검 → 1통 셀프 테스트 → 다일 안전 분산 발송.

7-2. Resend 발송 (인증 도메인 · 시뮬레이터 · 2차 미오픈 발송)

  • 발송 공급자 선택 → Resend 선택 → 🔗 원클릭 자동 페어링 및 Resend API 키 NTFS 보안 저장.
  • 🧪 시뮬레이터 테스트(delivered/bounced/complained@resend.dev) → 📨 실제 테스트 1통 → 🚀 대량발송 시작.
  • 실시간 진행률 모니터 & 2차 미오픈 발송: 🔎 Resend 이력 대조로 전달/오픈/반송을 동기화한 뒤, 지정 시간 경과 후 🚀 2차 발송 — 미오픈 대상만으로 반송·신고·수신거부 제외 후속 발송 실행.

8. 앱 내 1클릭 GitHub 최신 업데이트 & 안전한 제거

🔄 앱 내 1클릭 GitHub 자동 업데이트

  1. Email Studio 맨 위 헤더 우측의 파란색 🔄 최신 업데이트 확인 버튼을 클릭합니다.
  2. GitHub 공식 릴리스(goodkie/v-show)에 새 버전이 있으면 ⬇️ 최신 버전 다운로드 후 설치 버튼이 나타납니다.
  3. 클릭 시 공식 HTTPS 자산만 다운로드하고 .sha256.txt와 SHA-256 해시를 검증(불일치 시 자동 삭제·차단)한 뒤 %LOCALAPPDATA%\XPIDER\Sidecar의 모든 키·OAuth·계정·원장을 100% 보존한 채 업그레이드하고 Sidecar를 자동 재시작합니다.
  4. 설치 완료 안내 후 Chrome chrome://extensions에서 XPIDER 새로고침(🔄)을 클릭하면 새 버전이 적용됩니다.

🗑️ 안전한 제거

%LOCALAPPDATA%\XPIDER\App\UNINSTALL_XPIDER.bat 를 실행하면 기본적으로 사용자 데이터(%LOCALAPPDATA%\XPIDER\Sidecar)를 보존한 채 앱과 레지스트리만 깔끔히 제거합니다.

10. 컴플라이언스 · 계정 보호 및 정직한 고지

개인 로컬 통합 패키지 보안 엄수: LOCAL_PRIVATE_ONLY 폴더 안의 PERSONAL_LOCAL_ONLY 설치기/압축파일에는 본인의 실제 API 키와 OAuth 설정이 들어 있습니다. 절대로 GitHub, 공개 클라우드, 외부 메신저에 업로드하지 마시고 본인 소유 PC 간 이동에만 사용하세요.

  • 정직한 도달률 고지: 본 도구의 스팸 방지 위생 기능과 Gmail 웹 작성창·랜덤 페이싱은 스팸 분류와 계정 정지 위험을 낮추는 데 도움을 주지만, 100% 기본 받은편지함(Primary) 배치나 계정 정지 면제를 보장하지 않습니다.
