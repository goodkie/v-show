# XPIDER 이메일 템플릿 제작기 — 로컬 실행 방법

개발 브랜치: `feature/consent-based-email-delivery-20261109`

## 현재 구현
브라우저에서 `tools/email-template-studio.html` 파일을 여는 독립형 로컬 웹 편집기입니다. **REV22 ZIP과 확장 팝업에 통합되지는 않았습니다.** 템플릿 제작 기능을 새 발송 체계와 분리하여 테스트할 수 있게 설계했습니다.

- 제목 / 미리보기 문구 / 로고 대신 텍스트 브랜드 / 본문 / 버튼 / 회사명 / 실제 회사 주소 / 회신 주소 / 수신거부 URL 편집.
- 이미지: 공개 HTTPS URL을 사용해 HTML로 내보내거나, 사용자 PC에서 업로드한 PNG/JPEG/WebP/GIF(최대 3MB)를 *미리보기 전용*으로 사용합니다. 로컬 미리보기 파일을 HTML/Resend의 첨부 파일로 자동 등록하지 않습니다. CID 이미지는 별도의 Resend attachment API 구현이 필요합니다.
- 모바일/데스크톱 미리보기; HTML 파일, 일반 텍스트 파일 및 편집 템플릿 JSON 내보내기.
- 과장된 약속·오해를 부르는 제목·과도한 반복·이미지 전용 콘텐츠·alt 누락·불투명한 링크·수신 거부 및 사업자 정보 누락에 대한 **참고용** 휴리스틱 검토.
- 모든 작성 내용은 로컬 브라우저 내에서 처리; 템플릿 제작 중 이메일을 보내지 않습니다. iframe은 sandbox 상태이며 외부 스크립트를 불러오지 않습니다. 외부 HTTPS 이미지는 서버에 이미지 요청이 발생할 수 있습니다.

## 사용
1. GitHub 브랜치에서 `tools/email-template-studio.html`을 다운로드합니다.
2. PC의 Edge 또는 Chrome에서 파일을 엽니다.
3. 좌측에서 제목·본문·이미지·링크를 작성하고 오른쪽에서 미리보기를 확인합니다.
4. 작업이 완료되면 HTML과 TXT 양쪽을 모두 다운로드합니다. JSON으로 템플릿 초안을 저장할 수 있습니다.
5. **발송 전 별도 확인:** vivpr.pro DNS SPF/DKIM/DMARC, 인증된 Resend 도메인, 실존 Reply-To, 정상 수신 동의/업무 관계, Resend AUP, 수신거부 POST 처리와 List-Unsubscribe 헤더, 수신거부/반송 suppression, 테스트 주소로의 발송 결과, 그리고 현재 HTTP_407인 Privacy Relay 복구. 이 편집기가 이 항목을 자동 확인했다고 주장하지 않습니다.
6. 실제 이메일 서비스에 발송하려면 위 검증을 통과한 뒤 승인된 로컬 전송 파이프라인에서 HTML/TXT를 `html`/`text`로 전달하도록 통합해야 합니다. 현재 독립 도구로는 발송하지 않습니다.

## 스팸 판정에 관한 중요한 구분
- 단어 자체(예: '무료')가 곧 스팸을 의미하는 단순 금지어 목록은 정확하지 않습니다. 신뢰 가능한 발신자, 정확한 내용, 정상적인 수신자 관계와 적절한 제공 권한이 더 중요합니다.
- 이미지/텍스트 비율에 Gmail의 보편적인 숫자 기준은 없습니다. 이미지 한 장으로만 구성된 메일을 피하고 실제 텍스트와 대체 텍스트를 포함하는 품질 검사를 사용합니다.
- Mail-tester/Unspam 테스트 이메일도 실제 발송입니다. 테스트 수신 주소, 발송 서버, 계정 권한이 갖춰진 뒤 직접 승인된 테스트만 진행합니다.
- 제작기는 '스팸 방지 점수'나 받은편지함 도착 보장을 표시하지 않습니다.

## 검증
`node test/run_email_template_studio_static.js` 정적 안전성 테스트를 추가하고 기능 브랜치 전용 CI 설정에 포함했습니다. **이번 세션에서 실행된 테스트의 PASS 증거는 아직 없으며, 실제 사용자 PC에서 동작 검증도 UNKNOWN입니다.**

## 원칙
기존 설치된 REV22, XPIDER Privacy Relay, CSV·history·ledger·email collector, IVCS Manager 데이터는 변경하지 않음. 실발송 및 기존 팝업 통합은 출시 전 별도 승인을 거쳐야 함.
