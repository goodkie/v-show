# [AGY-Sync Master] 다중 PC 동시 개발 및 자동 설치·진단·복구 매뉴얼

본 시스템은 **어떤 PC(새 PC, 서브 PC, 작업실 PC 등)에서나 1-클릭으로 완벽하게 동일한 환경을 구축**하고, Antigravity + ChatGPT 협업 대화 이력과 Git 저장소 소스코드를 실시간으로 양방향 동기화하며, 손상 발생 시 스스로 진단하고 복구하는 **차세대 통합 동기화 플랫폼**입니다.

---

## 1. 핵심 아키텍처 (왜 이전 방식의 오류가 완벽히 해결되었는가?)

과거 구글 드라이브(G:)를 통해 4GB가 넘는 대용량 Git 팩파일(`.git`)을 직접 복사하던 방식은 **구글 드라이브 데스크톱의 비동기 스트리밍 결손(0x00 널 바이트 패딩 현상)**으로 인해 `git fetch` 및 체크아웃이 중단되는 치명적 한계가 있었습니다.

**[AGY-Sync Master]는 듀얼 채널(Dual-Channel) 분리 원칙을 확립했습니다:**
1. **소스 코드 & Git 이력 (무결점 채널)**:
   - 구글 드라이브를 거치지 않고 **GitHub 원격지(`origin`)에서 직접 클론 및 Fetch/Pull/Push**합니다.
   - 0바이트 손상 파일 원천 차단 및 무결한 커밋 히스토리를 보장합니다.
2. **Antigravity 세션 & 대화 브레인 (경량화 채널)**:
   - AI 대화창 세션(`conversations`), 아티팩트(`brain`), 대화 요약 DB(`conversation_summaries.db`)는 **Google Drive(`v-show-antigravity-sync/antigravity-core`)**를 통해 초고속 동기화됩니다.
3. **지능형 환경 경로 자동 재매핑 (Dynamic Path Remapper)**:
   - PC마다 다른 윈도우 계정명(`server4`, `oPus`, `server1` 등)이나 설치 드라이브(`C:\`, `D:\`, `E:\`)를 감지하여, 설정 파일(`app_storage.json`)과 SQLite DB 내의 경로를 **현재 PC 환경에 맞게 100% 자동 치환**합니다.

## 2. 제공되는 툴 및 1-클릭 실행 파일 목록

저장소 루트 및 Google Drive 최상단(`G:\내 드라이브\v-show-antigravity-sync\`)에 바로 실행 가능한 1-클릭 배치 파일이 배치되어 있습니다.

| 번호 | 실행 파일명 | 설명 |
| :---: | :--- | :--- |
| **00** | `[00_동기화_진단_복구_대시보드_실행].cmd` | **웹 UI 실시간 모니터링 대시보드** (포트 3900) 실행 및 브라우저 자동 오픈. 진행률 0~100% 및 실시간 터미널 로그 스트리밍 지원 |
| **01** | `[01_새PC_자동설치_환경매핑_1클릭].cmd` | **신규 PC 최초 셋업 전용**. GitHub 클론 + Worktree 생성 + 대화 이력 복원 + 경로 리매핑 + 의존성 설치를 한번에 수행 |
| **02** | `[02_작업완료_동기화_PUSH_1클릭].cmd` | **작업 종료 시 실행**. 작성한 코드를 GitHub에 안전 푸시하고, 최신 AI 대화/브레인을 구글 드라이브에 자동 백업 |
| **03** | `[03_작업시작_동기화_PULL_1클릭].cmd` | **작업 시작 시 실행**. 다른 PC에서 작업한 최신 코드 및 AI 대화 이력을 가져오고 현재 PC 경로로 즉시 리매핑 |
| **04** | `[04_저장소_정밀진단_자동복구_1클릭].cmd` | 손상된 팩파일 탐지/격리, Git 오브젝트 재수신, Git fsck 전수 검사를 통한 **원클릭 자가 치유** |
| **05** | `[05_환경경로_재매핑_1클릭].cmd` | 다른 PC에서 복사해온 세션의 사용자명/경로 오염만 즉시 현재 PC로 고속 치환 |

## 3. 상황별 표준 사용법 (Step-by-Step)

### 상황 A. 새 PC(또는 다른 작업용 PC)에 처음 설치할 때
1. 새 PC에서 **Google Drive 데스크톱**이 로그인되어 있고 `G:\` 드라이브가 마운트되어 있는지 확인합니다.
2. 탐색기에서 `G:\내 드라이브\v-show-antigravity-sync\` 폴더를 엽니다.
3. **`[01_새PC_자동설치_환경매핑_1클릭].cmd`** 를 더블클릭합니다.
4. 진행 과정(0% -> 100%)이 터미널에 시각적 프로그레스 바로 표시되며 완료됩니다.
5. 설치 완료 후 **Antigravity IDE**를 실행하면 이전 PC에서 나누었던 모든 대화 기록과 최신 코드가 그대로 복원되어 있습니다.

### 상황 B. PC 1에서 작업 후 -> PC 2로 이동하여 이어서 작업할 때
- **[PC 1에서 퇴근 / 작업 종료 시]**
  1. 작업이 끝나면 **`[02_작업완료_동기화_PUSH_1클릭].cmd`** 를 더블클릭합니다.
  2. 코드가 GitHub에 올라가고, 방금 나눈 대화 세션이 구글 드라이브로 백업됩니다.
- **[PC 2에서 작업 시작 시]**
  1. **`[03_작업시작_동기화_PULL_1클릭].cmd`** 를 더블클릭합니다.
  2. PC 1에서 작업했던 코드와 대화 내용이 즉시 내려받아지며, PC 2의 경로로 자동 치환됩니다.
  3. Antigravity IDE에서 끊김 없이 작업을 이어갑니다.

### 상황 C. 동기화 상태 모니터링 및 시각적 제어가 필요할 때 (대시보드)
1. **`[00_동기화_진단_복구_대시보드_실행].cmd`** 를 더블클릭합니다.
2. 웹 브라우저(`http://localhost:3900`)에 다크모드 글래스모피즘 대시보드가 열립니다.
3. 현재 PC 상태, 종합 건강도 점수(100점 만점), 세부 검사 항목 7종을 시각적으로 확인합니다.
4. 화면 상단의 **[새 PC 설치]**, **[작업 PUSH]**, **[작업 PULL]**, **[정밀진단/복구]**, **[경로 리매핑]** 버튼을 클릭하여 웹에서 직접 작업을 수행하고 실시간 진행률(0~100%)과 로그를 모니터링할 수 있습니다.
5. *(선택사항)* 동일 공유기/네트워크에 있는 스마트폰이나 노트북 브라우저에서도 `http://<현재PC-IP>:3900`으로 접속하여 원격 모니터링이 가능합니다.

### 상황 D. 팩파일 깨짐이나 Git 오류가 발생했을 때
1. **`[04_저장소_정밀진단_자동복구_1클릭].cmd`** 를 더블클릭합니다.
2. 엔진이 손상된 팩파일을 자동으로 감지하여 격리 폴더로 치우고, GitHub에서 깨끗한 커밋 체인을 재수신하여 100% 정상 상태로 복원합니다.

---

## 4. 향후 신규 프로젝트(앱 개발) 확장 방법

본 엔진(`tools/agy-sync-master/engine.js`)은 독립 모듈로 설계되어 있어, 향후 새로운 프로젝트를 시작할 때도 매우 간단히 적용할 수 있습니다:
- `engine.js`의 `githubRepoUrl`, `defaultBranch`, `syncPackageName` 설정만 변경하거나, 환경변수로 지정하면 어떤 신규 웹/앱 프로젝트에서도 완벽히 동일한 다중 PC 동시 협업 인프라를 누릴 수 있습니다.
