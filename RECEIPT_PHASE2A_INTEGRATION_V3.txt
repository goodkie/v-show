=== F7 — SOURCE ROW PRESERVATION (PRODUCTION PATH FIXED) ===

PRIOR FINDING: allRawUrls was produced by regex extraction AFTER URL parsing. Non-URL
rows never entered the ledger. sourceRowId reflected URL-match ordinal, not actual file line number.

PRODUCTION FIX (popup.js handleFileUpload):
  Step 1: text.split(/\r?\n/) — split file into raw lines BEFORE any regex extraction.
  Step 2: Build rowsForLedger = rawSourceRows.map((rawLine, idx) => ({
              sourceRowNumber: idx + 1,  // actual 1-indexed file line number
              rawInput: rawLine          // exact original content including non-URLs
          }));
  Step 3: chrome.runtime.sendMessage({ action: 'RECORD_IMPORT_ROWS', rows: rowsForLedger, importId })
          — sent with full structured rows (not URL-only array) BEFORE any extraction.
  Step 4: ONLY THEN: text.match(urlRegex) for execution queue.

BACKGROUND HANDLER FIX (background.js RECORD_IMPORT_ROWS):
  Accepts rows:[{sourceRowNumber, rawInput}] from popup.
  Passes rawInputs[] + sourceRowNumbers[] to ingestImportRows().

HISTORY-STORE FIX (modules/history-store.js ingestImportRows):
  New signature: ingestImportRows(rawInputs, importId, sourceRowNumbers=null)
  If sourceRowNumbers provided: uses actual file line number as sourceRowId.
  Every row (empty, non-URL text, partial URL) gets its actual row identity.

=== F8 — CANONICAL SENDER ATTEMPT LIFECYCLE (PRODUCTION PATH FIXED) ===

PRIOR FINDING: (1) No suppression check before tab open; (2) recordAttempt failure did not
block send; (3) dual ledgers (HistoryStore + xpider_currentAttempt) diverged; (4) DELIVERY_UNKNOWN
collapsed into FAILURE; (5) CHECK_SUPPRESSION used raw URL, HistoryStore used normalized identity.

PRODUCTION FIX (background.js orchestrateSending):
  Step 1 — Suppression check BEFORE tab open:
    normalizedId = hs.normalizeTargetIdentity(targetUrl)
    if (hs.isSuppressed(normalizedId)) return { success:false, reasonCode:'SUPPRESSED' }
  Step 2 — Abort on intent persistence failure:
    if recordAttempt() throws or returns no attemptId:
      return { success:false, reasonCode:DELIVERY_UNKNOWN, error:'INTENT_PERSISTENCE_FAILED' }
    (tab is NEVER opened if intent cannot be persisted)
  Step 3 — Unify legacy currentAttempt with HistoryStore:
    campaignState.currentAttempt = { url, attemptId: _attemptId, status:'SUBMIT_PENDING', ts }
    — same attemptId carried for recovery; no separate parallel ledger
  Step 4 — DELIVERY_UNKNOWN preserved distinctly:
    isDeliveryUnknown = !isSuccess && (!res.error && !res.reasonCode || res.reasonCode === DELIVERY_UNKNOWN)
    if isDeliveryUnknown: finalReason = DELIVERY_UNKNOWN (not FAILURE)
  Step 5 — settleAttempt with DELIVERY_UNKNOWN vs FAILURE:
    DELIVERY_UNKNOWN → suppresses target (prevents blind resend on restart recovery)
    FAILURE → does NOT suppress target (remains retryable)
  Step 6 — CHECK_SUPPRESSION RPC normalizes identity:
    normalizedId = hs.normalizeTargetIdentity(request.targetUrl)
    isSup = hs.isSuppressed(normalizedId || request.targetUrl)

HISTORY-STORE FIX (settleAttempt):
  if (isSuccess || attempt.reasonCode === 'DELIVERY_UNKNOWN') → suppress
  FAILURE: isSuppressed remains false — target stays retryable
