### 3. Comprehensive Hardening Against All 3 Audit Blockers

- **Manifest Permission**: Added `"declarativeNetRequest"` to `manifest.json`.
- **Dynamic Session Rules Architecture (Rules 990001–990005)**:
  - **Priority 1 (Deny All Public Traffic)**:
    - Rule 990001: Blocks `|http*` across `main_frame`, `sub_frame`, `stylesheet`, `script`, `image`, `font`, `object`, `xmlhttprequest`, `ping`, `csp_report`, `media`, `websocket`, `other`.
    - Rule 990002: Blocks `|ws*` across all request resource types.
  - **Priority 2 (Allow Loopback Only)**:
    - Rule 990003: Allows `||127.0.0.1^`.
    - Rule 990004: Allows `||localhost^`.
    - Rule 990005: Allows `||[::1]^`.
- **Fail-Closed Lifecycle & Pre-START Verification**:
  - `installOwnerTestNetworkGuard()` runs before `START_CAMPAIGN` acknowledges.
  - Verifies readback via `chrome.declarativeNetRequest.getSessionRules()`. If installation or readback fails, campaign aborts immediately with `FAIL-CLOSED: Network guard installation failed`.
- **Clean Removal Invariant**:
  - Automatically uninstalled when campaign finishes, is stopped, paused, or when Owner Test Mode toggle is turned OFF.
  - Startup sweeper uninstalls lingering test rules on Service Worker initialization.
